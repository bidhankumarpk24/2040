# 2048 Master

**Merge. Think. Master the Board.**

2048 Master is a polished, responsive, browser-based version of the classic 4×4 2048 puzzle. It is built as a lightweight static website and works without a server, framework, build step, or external dependency.

## Features

- Classic 4×4 2048 gameplay with correct one-merge-per-move logic
- Arrow keys, WASD, and mobile swipe controls
- Score, persistent best score, undo, new game, win continuation, and game-over handling
- Dark/light theme preference saved locally
- Optional lightweight Web Audio sound effects
- Web Share API with clipboard fallback
- Responsive, touch-friendly, accessible interface
- SEO metadata, semantic HTML, reduced-motion support, and a text/emoji favicon

## Technologies

HTML5, CSS3, and vanilla JavaScript only.

## Run locally

Open `index.html` directly in a modern browser. No installation or build process is required. For a local static server, any simple HTTP server will work, but it is not necessary.

## Deploy to GitHub Pages

1. Push the project files to a GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. GitHub Pages will publish `index.html` automatically.

## Controls

- **Arrow keys / WASD:** Move tiles
- **Swipe:** Move tiles on touch devices
- **New Game:** Reset the board and score
- **Undo:** Restore the previous valid move
- **Continue Game:** Keep playing after reaching 2048
- **Share Score:** Share or copy the current score
